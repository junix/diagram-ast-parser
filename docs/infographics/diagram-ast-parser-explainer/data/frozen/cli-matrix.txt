# 错误与行为演示（stdin 输入；诊断 JSON 走 stderr，此处合并转录）
$ printf 'a: {\n  b: c\n' | diagram-parse --format d2 --diagnostic-json -   -> rc=1
{
  "format": "d2",
  "message": "unterminated block: expected `}`",
  "span": null,
  "line": 1,
  "column": 1
}
